## 9. Submission Process

### Pre-submission:

1. [ ] Run `devtools::check()` - fix all ERRORs and WARNINGs
2. [ ] Run `covr::package_coverage()` - ensure ≥90%
3. [ ] Run `BiocCheck::BiocCheck()` - address all issues
4. [ ] Update DESCRIPTION with Bioconductor fields
5. [ ] Update README with Bioconductor badges
6. [ ] Ensure vignettes build correctly
7. [ ] Verify all examples run without errors

### Submission Steps:

1. **Create Bioconductor Git Repository**
   - Follow https://bioconductor.org/developers/package-git-repository/
   - Repository will be at `git@git.bioconductor.org:packages/CyFj11.git`

2. **Initial Commit**
   ```bash
   git clone git@git.github.com:baj12/CyFj11.git
   cd CyFj11
   git remote add bioc git@git.bioconductor.org:packages/CyFj11.git
   git push bioc main
   ```

3. **Package Builds Automatically**
   - Bioconductor build system will pick up the package
   - Monitor build status at https://bioconductor.org/checkResults/

4. **Address Any Build Issues**
   - Respond to automated emails from build system
   - Fix issues promptly
