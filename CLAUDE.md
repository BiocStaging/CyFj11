# CyFj11 — Claude Code Project Guide

## Project Overview

**CyFj11** is an R/Bioconductor package that parses FlowJo v11 workspace files (`.flowjo`) and extracts gating hierarchies, populations, transformations, and associated FCS files. It also supports exporting `GatingSet` objects back to the FlowJo v10 XML workspace format.

- **Language**: R (>= 4.0.0)
- **Package type**: Bioconductor package with `roxygen2` documentation
- **Main repo**: `https://github.com/baj12/CyFj11`
- **Current version**: 0.9.3
- **License**: MIT + file LICENSE

## Key R Source Files

- `R/export-flowjo10.R` — Export `GatingSet` objects to FlowJo v10 XML format.
- `R/export-workspace.R` — Workspace-level export utilities.
- `R/conversion.R` — Convert parsed FlowJo v11 structures into `GatingSet`/R objects.
- `R/populations.R` — Population extraction and manipulation.
- `R/gates.R` — Gate parsing and helpers.
- `R/transformations.R` — FlowJo transformation parsing/serialization.
- `R/compensation.R` — Compensation matrix handling.
- `R/file-search.R` — FCS file discovery and matching.
- `R/helpers.R`, `R/helpers-conversion.R` — Internal helpers.
- `R/pretty_print_flowjo.R` — Pretty-printing of FlowJo JSON structures.
- `R/uuid-construction.R`, `R/workspace-creation.R` — Workspace construction internals.
- `R/archive.R` — Archive/workspace backup utilities.
- `R/package.R`, `R/CyFj11-package.R` — Package metadata.

## Key Exported Functions

- `read_flowjo11_workspace()` — Main entry point to parse a FlowJo v11 workspace.
- `fj11_to_gatingset()` — Convert parsed workspace to a `GatingSet`.
- `export_flowjo10_workspace()` — Export a `GatingSet` to FlowJo v10 XML.
- `set_verbose()` / `get_verbose()` — Toggle diagnostic output.

## Development Conventions

- Document all exported functions with `roxygen2` comments.
- Run `devtools::document()` after editing documentation.
- Run `devtools::test()` or `testthat::test_package("CyFj11")` to execute tests.
- Use `R CMD check` (or `devtools::check()`) before Bioconductor submission.
- Keep example data small; large `.fcs`/`.RData` files should not be committed.
