# Zenodo Upload Guide for CyFj11 Validation Dataset

## What to upload

Upload the contents of `flowjo_export_tests/` (but not `.DS_Store` files):

```
flowjo_export_tests/
├── README.txt
├── generate_all_tests.R
├── validation_counts.csv
├── validation_counts.tsv
├── validation_transforms.tsv
├── history.txt
├── test01/
├── test02/
├── test03/
├── test04/
├── test05/
├── test06/
├── test07/
├── test08/
├── test09/
├── test10/
├── test11/
├── test12/
├── test13/
└── test14/
```

Each `testNN/` directory contains:

- `*.fcs` — FCS file(s)
- `*_export.wsp` — CyFj11-exported FlowJo v10 workspace
- `*_export.llm.wsp` — copy of the exported workspace

## Data provenance

- **Tests 01–13**: entirely synthetic FCS data generated by `generate_all_tests.R`. No human or patient-derived material.
- **Test 14**: public example data from the Bioconductor `FlowSOM` package (`68983.fcs` and `gating.wsp`).

## How to upload to Zenodo

### Option A: web interface (recommended)

1. Go to https://zenodo.org and log in.
2. Click **Upload** → **New upload**.
3. Drag and drop the files/directories listed above.
4. Also upload `.zenodo.json` — Zenodo will pre-fill metadata fields.
5. Review and complete the metadata form.
6. Click **Reserve DOI**.
7. Click **Publish**.

### Option B: paste metadata manually

If you do not upload `.zenodo.json`, fill in the Zenodo form using:

- **Title**: CyFj11 validation suite: synthetic test workspaces, FCS files, and analysis scripts for FlowJo v11 / R interoperability
- **Authors**: Jagla, Bernd (Institut Pasteur, ORCID 0000-0002-7696-0484)
- **Description**: copy from `.zenodo.json` `"description"` field
- **Keywords**: flow cytometry, FlowJo, GatingSet, Gating-ML, workspace interoperability, R, Bioconductor, CyFj11, validation
- **License**: MIT
- **Upload type**: Dataset
- **Related identifiers**:
  - https://github.com/baj12/CyFj11 (isSupplementTo, software)
  - https://bioconductor.org/packages/FlowSOM (isDerivedFrom, software)
  - https://github.com/baj12/CyFj11/tree/main/manuscript (isDescribedBy, publication-article)

## After publishing

1. Note the reserved DOI (e.g., `10.5281/zenodo.XXXXXXX`).
2. Replace `[TODO: Zenodo DOI]` in `manuscript/cyfjll_manuscript.Rmd` with the real DOI.
3. Update the README if it also references the Zenodo DOI.
